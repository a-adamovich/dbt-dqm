# 0.2.0a2 release candidate evidence

Python support expands to 3.11–3.14 (`>=3.11,<3.15`), with 3.14 recommended.
The migration keeps dbt-core 1.12.5, dbt-bigquery 1.12.1 and dbt-postgres 1.11.x.
Mashumaro 3.17 fixes dbt initialization on Python 3.14; Streamlit requires at least 1.52.
The AI Platform/GenAI dependency branch is repaired without refreshing unrelated versions.
No warehouse schema migration is introduced.

Candidate and gate results will be recorded after validation. Publication remains pending.
